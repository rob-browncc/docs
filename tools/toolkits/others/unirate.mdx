**UniRateTools** enable an Agent to access currency exchange rates, currency conversion, supported currencies, and VAT rates from the [UniRate API](https://unirateapi.com).

## Prerequisites

The following example requires the `httpx` and `openai` libraries and a free API key which can be obtained from [UniRate](https://unirateapi.com).

```shell
uv pip install -U httpx openai
```

```shell
export UNIRATE_API_KEY=***
```

## Example

The following agent will use UniRate to convert an amount between currencies and report the current exchange rate.

```python cookbook/91_tools/unirate_tools.py
from agno.agent import Agent
from agno.tools.unirate import UniRateTools

# Create an agent with UniRateTools
agent = Agent(
    tools=[
        UniRateTools(
            base_currency="USD",  # Default source currency for conversions
        )
    ],
    markdown=True,
)

# Convert an amount between currencies
agent.print_response("Convert 100 US dollars to euros.", markdown=True)
```

## Toolkit Params

| Parameter                  | Type   | Default | Description                                                                       |
| -------------------------- | ------ | ------- | --------------------------------------------------------------------------------- |
| `api_key`                  | `str`  | `None`  | UniRate API key. If not provided, uses the `UNIRATE_API_KEY` env var.             |
| `base_currency`            | `str`  | `USD`   | Default base (source) currency as an ISO 4217 code.                               |
| `enable_get_exchange_rate` | `bool` | `True`  | Enable the exchange-rate function.                                                |
| `enable_convert_currency`  | `bool` | `True`  | Enable the currency-conversion function.                                          |
| `enable_list_currencies`   | `bool` | `True`  | Enable the supported-currencies function.                                         |
| `enable_get_vat_rate`      | `bool` | `True`  | Enable the VAT-rate function.                                                     |
| `all`                      | `bool` | `False` | Enable all functions.                                                             |
| `timeout`                  | `int`  | `30`    | Per-request HTTP timeout in seconds.                                              |

## Toolkit Functions

| Function            | Description                                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| `get_exchange_rate` | Gets the current exchange rate between two currencies. Takes a target currency code and an optional source code.  |
| `convert_currency`  | Converts an amount from one currency to another. Takes an amount, a target currency code, and an optional source. |
| `list_currencies`   | Lists all currency codes supported by the UniRate API.                                                            |
| `get_vat_rate`      | Gets VAT rates. Takes an optional ISO-3166 alpha-2 country code; returns all countries when omitted.              |
